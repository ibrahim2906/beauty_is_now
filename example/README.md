# beauty_is_now Example

This example demonstrates how to use the `beauty_is_now` package widgets:
- `BeautySegmentedBar` (Fluid interactive segmented control)
- `BeautyWindow` / `showBeautyWindow` (Glassmorphic modal dialog with close and confirm buttons)
- `BeautyNavBar` (Draggable navigation bar with spring physics)

## Running the Example

Run the following command from the `example` directory:

```bash
flutter run
```

## Preview in DartPad

DartPad only supports a small, pre-approved list of pub.dev packages, so it
cannot import `beauty_is_now` directly. `dartpad_demo.dart` is a self-contained
version of the demo with the package sources inlined:

1. Open [dartpad.dev](https://dartpad.dev) and choose **Flutter**.
2. Replace the editor contents with `example/dartpad_demo.dart`.
3. Press **Run** and drag the active pills.

To share a runnable DartPad link, save the file as `main.dart` in a public
[gist](https://gist.github.com), then open
`https://dartpad.dev/?id=<gist-id>`.
