# beauty_is_now Example

This example demonstrates how to use the `beauty_is_now` package widgets:
- `BeautySegmentedBar` (Fluid interactive segmented control)
- `BeautyWindow` / `showBeautyWindow` (Glassmorphic modal dialog with close and confirm buttons)
- `BeautyNavBar` (Draggable navigation bar with spring physics)

## Running the Example

Run the following command from the `example` directory:

```bash
flutter run
```
